# The Strategy Deck — Art Assets

**Style decision:** the deck's identity is the cartographer's table — aged
contour maps, brass instruments, lamplight on navy. Every prompt starts with
this canonical prefix:

```
moody cartographer photograph, a dark wooden map table by lamplight, aged
paper maps with topographic contour lines, brass compass and dividers, deep
navy and antique gold palette, dramatic chiaroscuro, soft film grain,
strategic quiet atmosphere, generous dark negative space
```

Every prompt ends with: `no text, no letters, no words`

Regenerate with `limn generate -s <size> -o <path> "<prefix>, <subject>, no
text, no letters, no words"` (default SwarmUI, juggernautXL_v9). Sidecars
(.png.json) record the exact prompts.
